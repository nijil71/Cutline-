Cutline

Screenshots named from what is actually on the page.

Where files go

Extensions may only write inside your Downloads folder, so every path below is relative to it.

Naming

Preview

    After capture

    The prompt is the moment the file is written, not a correction afterwards — the browser offers no way to rename a completed download. The image reaches your clipboard immediately either way.

    Private sites

    One host glob or /path fragment per line. Matches always save as a bare timestamp — the filename itself leaks, and amex-statement-balance-42000.png in a screenshare is an exposure a timestamp never was.

    Folder rules

    One rule per line, host-glob => Folder. Rules match on host only — never on a guess about what the screenshot means, so a misfile is always something you can point at and fix.

    How to capture

    Ctrl+Shift+S for a region, Ctrl+Shift+E for the visible page, Ctrl+Shift+F for the full scrolling page. Shortcuts only fire while the browser has focus.

    The toolbar icon always captures a region, and right-clicking any page offers all three modes — so nothing is out of reach if a shortcut is taken by something else.

    On Brave, rebind this. Brave reserves Ctrl+Shift+S for its own screenshot tool, and browser shortcuts win over extension ones — you will get Brave's dialog instead of Cutline. Alt+Shift+S is free. The toolbar icon always works either way.
